# GitHub Assignment 2

This repo holds my Assignment 2 notebook which walks through basic Git operations in Google Colab.

## What the notebook does

- Defines a small `multiply_numbers(a, b)` function and tests it (`3 * 4 = 12`)
- Configures Git with a username and email
- Stages and commits the notebook
- Connects the local repo to this GitHub repo
- Pushes the commit to the `main` branch

## How to run it

1. Open the notebook in Google Colab .
2. Run the cells from top to bottom.
3. To push to your own repo, add a GitHub token in Colab Secrets (🔑 icon) under the name `GITHUB_TOKEN`.
